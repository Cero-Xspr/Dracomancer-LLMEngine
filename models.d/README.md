# models.d/ —— 模型适配注册表

每个 `*.json` 是一份**模型档案**：告诉 draco 这类模型该用什么参数跑。
纯数据、白名单字段、**永不执行代码**。完整 schema、提交流程和验证方式见
[`../AGENT_ADAPTER.md`](../AGENT_ADAPTER.md)（写给做适配的 agent/人读）。

- 文件按名字排序加载，`match` 规则命中**第一份**生效（多条命中会打印警告）；
- 坏文件（schema 不对/白名单外字段）会被**跳过并打印错误**，不影响其它档案；
- `models.d/` 整个丢失时有一条内置兜底（zaya），并打印警告。

现有档案：

| 文件 | 架构 | 要点 |
|---|---|---|
| `zaya.json` | `zaya` | 需本地构建；必须 `-ub 1`（逐 token prefill） |

（模板见 `../release/`），人工审核后由维护者落进本目录。
